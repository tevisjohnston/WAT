Before you start

Have these four things ready

  • A WordPress site you can log into as an administrator. The theme needs WordPress 6.6 or newer and PHP 8.1 or newer. Any good host meets both.
  • A GetResponse account with a list. The emails you send to new subscribers run as a GetResponse automation workflow. Automation workflows need a paid plan, and new accounts get them free for the first 14 days.
  • Your affiliate link: the full link from WarriorPlus, starting with https://.
  • The theme file, affiliate-theme.zip, from the Domain + Web Hosting step of your members area.

Nothing goes public until you publish it

The theme creates every page as a draft. You can take your time with each step. Visitors see a page only after you click Publish.

Step 1

Download the theme

In your members area, open the Domain + Web Hosting step and download affiliate-theme.zip.

Keep it zipped. WordPress installs the .zip file exactly as you downloaded it. Don't open it, rename it, or change what's inside.

On a Mac, Safari may unzip it for you

If your Downloads folder shows a folder called affiliate-theme instead of affiliate-theme.zip, right-click the folder and choose Compress “affiliate-theme”. That makes a new affiliate-theme.zip you can upload. To stop Safari doing this, turn off Safari › Settings › General › Open “safe” files after downloading.

Step 2

Upload and install the theme

Log in to your dashboard at yoursite.com/wp-admin.

  1. In the left menu, click Appearance. The Themes screen opens.
  2. Click Add Theme at the top.
  1. Click Upload Theme next to the Add Themes title.
  2. Click Choose File and pick affiliate-theme.zip.
  3. Click Install Now. After a few seconds WordPress says Theme installed successfully.
Step 3

Activate the theme

On the Theme installed successfully. screen, click Activate. If you've already left that screen, go to Appearance › Themes, point at the Affiliate Theme card and click Activate.

What activation creates for you

The moment you activate it, the theme adds seven pages, all as drafts:

  • Three landing pages, the same offer in three layouts: Landing Page — Centered, Landing Page — Split and Landing Page — Long Form. You'll use one.
  • Four legal pages: Privacy Policy, Terms of Service, Earnings Disclaimer and Affiliate Disclosure.

It also adds a new screen under Settings › Affiliate Theme Settings, which is where Step 5 happens.

Step 4

Set your permalinks

Go to Settings › Permalinks.

Permalinks are your pages' web addresses. Post name gives each page a short, readable one, such as yoursite.com/privacy/. Set it now, before you publish anything, so no address changes after you share it.

  1. Under Permalink structure, choose Post name. The Custom Structure box below it changes to /%postname%/.
  2. Click Save Changes at the bottom of the screen.
Step 5

Connect GetResponse and your affiliate link

Go to Settings › Affiliate Theme Settings.

This one screen wires up your whole funnel. Fill it in from top to bottom. The numbers match the screenshot.

  1. GetResponse API key. In GetResponse, go to Tools › Integrations and API › API, generate a key and copy it (pictured below). Paste it here. After you save, the field shows only dots and the key is never displayed again. It stays on your server and is never sent to visitors' browsers or shown on your pages. To change it, type a new key over the dots. A key that goes unused for 90 days stops working, so make a new one if the funnel sits idle that long.
  2. GetResponse list token. This is a short code that identifies your list, such as 7qhMJ. It is not the list's name. In GetResponse, open your list's settings. The token is under the box labelled List name (pictured below).
  3. Check list. Click it to test the key and token together. The note below the list changes to GetResponse accepted this list.
  4. GetResponse list. This shows your list's name with its token after a successful check. It only displays the list. The token field is what gets saved, so if you change the token, click Check list again before you save.
  5. Affiliate redirect URL. Paste your full affiliate link, starting with https://. Each new subscriber's browser is sent here. The link never appears in your page's code, so nobody can copy it without subscribing first.
  6. Click Save Changes.

Get your API key in GetResponse

  1. Click Tools in the top bar.
  2. Under Connect, click Integrations and API.
  3. Click the API tab.
  4. Click Generate API key.
  5. Type a name you'll recognize, such as your site's name. Click Generate.
  6. Click Copy and paste the key into GetResponse API key. GetResponse shows each key only once.

Find your list token

In GetResponse, open your list's settings. The token is the short code after List token:, under the List name box. Copy only the token, not the List ID next to it.

Step 6

Edit and publish your landing page

Scroll down the same Affiliate Theme Settings screen to Your landing pages. Pick the layout you like and click its title to open it in the editor.

Publish only the landing page you use

Every published page is added to your site's menu automatically, so leave the other two layouts as drafts.

Every headline, paragraph, list and image can be edited: click it and type, or replace the image. The opt-in form is the one exception. You don't edit it on the page itself:

  1. Click the form. The Form panel on the right holds its Button text, the Email field label, the Ask for a first name switch and the Name field label. If the right-hand panel is closed, click the square Settings icon next to Publish.
  2. When the page reads the way you want, click Publish. WordPress asks Are you ready to publish?, so click Publish once more.
Step 7

Make the landing page your home page

Go to Settings › Reading.

  1. Under Your homepage displays, choose A static page (select below).
  2. In the Homepage list, choose the landing page you published in Step 6.
  3. Click Save Changes.

Now visit your site's address. Your landing page is the first thing people see.

Is your landing page missing from the list?

This list shows only published pages. Go back to Step 6 and click Publish.

Step 8

Fill in and publish your legal pages

Go back to Settings › Affiliate Theme Settings and scroll to Your legal pages. Click each page's title to open it in the editor.

Each page is written in plain English and uses square-bracket placeholders wherever your own details belong. Replace every one, on all four pages. Each placeholder is spelled the same way everywhere, so your browser's find command (Ctrl + F, or Cmd + F on a Mac) finds them all.

PlaceholderReplace it with
[Your Business Name]Your name or your business's legal name
[yoursite.com]Your domain, for example mysite.com
[you@example.com]An email address where visitors can reach you
[Your Mailing Address]Your postal address
[Your State/Country]The state or country whose law applies to your business
[Month Day, Year]The date the page takes effect, usually the day you publish it

Then click Publish on each page. A published legal page adds its own link to your site's footer, and that footer also appears at the bottom of your landing page. Draft pages are never linked.

If you ever add analytics, advertising or cookies

Your Privacy Policy says you don't sell or share visitors' information. That stays true only while your site runs no analytics, no advertising pixels and no tracking cookies. If you add Google Analytics, a Facebook pixel or any similar tool, follow the If you add analytics, advertising or cookies steps on the Affiliate Theme Settings screen. They swap in a ready-made section, Legal — Privacy: Analytics and Advertising, with one more placeholder, [Provider Name], for each tool you use.

Keep each page true to your business. These pages are a starting template, not legal advice.

Step 9

Point WordPress at your Privacy Policy

Go to Settings › Privacy.

WordPress creates its own draft privacy page when it's installed, so your page list now has two pages called Privacy Policy. Tell WordPress to use the theme's page, the one you just filled in and published.

  1. Open the Change your Privacy Policy page list. Privacy Policy appears twice. The one with the checkmark is WordPress's own unpublished draft, so choose the other Privacy Policy.
  2. Click Use This Page.

Check you picked the right one

After you click Use This Page, the top of the Privacy screen reads Edit or view your Privacy Policy page content. Click view. Your page opens with the line Effective date: and the date you entered. If the line says preview instead of view, you picked WordPress's unpublished draft. Choose the other entry and click Use This Page again.

Finish

Test your funnel

  1. Open a private or incognito browser window and go to your site's address.
  2. Type an email address you own into the form and submit it.
  3. Your browser should land on your affiliate link. That's the whole funnel working.
  4. In GetResponse, open Contacts. The new contact can take a few minutes to appear, because GetResponse processes new sign-ups in a queue.

If you submit the same address again, you're still sent to your affiliate link, because returning subscribers aren't turned away. Submitting the same address twice within a minute shows Please try again in a moment. Wait a minute before testing it again.

Help

Troubleshooting

Uploading the theme shows The theme is missing the style.css stylesheet.

You uploaded a different zip, or one whose contents were changed. Download affiliate-theme.zip again and upload it exactly as downloaded (see the Mac note in Step 1).

Uploading shows The link you followed has expired.

Reload the Add Themes page and upload again. If it keeps happening, your host's upload limit is too small. The theme is about 1 MB, so ask your host to allow uploads of at least 2 MB.

WordPress says This theme is already installed.

You're uploading a newer copy over an older one. Click Replace installed with uploaded. Your pages are safe: a theme update never overwrites a landing page or legal page you've edited.

My landing page says Opt-in form is not ready.

Step 5 isn't finished. Add your API key and list token, then save. Only administrators see this note. Until then, visitors see no form at all.

Saving shows That does not look like a GetResponse API key.

The text you pasted isn't a key. A key is at least 16 letters and numbers with no spaces. GetResponse shows each key only once, so if you no longer have it, generate a new one in Tools › Integrations and API › API. Your previous key, if you had one, is kept.

Check list says GetResponse rejected the API key.

The key is wrong or has expired (keys stop after 90 days unused). Make a new key in GetResponse, paste it in, then save.

Check list says GetResponse did not accept that list token.

You probably pasted the list's name or the List ID. The token is the short code, such as 7qhMJ, under the List name box, next to the List ID in the list's settings.

Saving shows The affiliate redirect URL is not a usable address.

Paste the complete link, including the https:// at the start.

Visitors see Something went wrong. Please try again.

GetResponse turned the sign-up down. Go to Settings › Affiliate Theme Settings, click Check list and fix whatever it reports. The most common cause is an expired API key.

A legal page isn't in my footer

Only published pages are linked. Open the page and click Publish. The link then appears on every page at once.

How do I change the copyright line in the footer?

Go to Appearance › Editor, open the footer, click the © 2026 — All rights reserved. line and type your own. Then save.

The legal pages that come with this theme are a starting template, not legal advice. Review them for your own business, or have a professional review them.
